# Maze Generator & Pathfinding

Программный стенд на языке Java для генерации двумерных идеальных лабиринтов и наглядного сравнения алгоритмов поиска кратчайшего пути.

## Ключевые возможности и особенности текущей версии
- **Генерация лабиринтов**:
  - **DFS** 
  - **Алгоритм Краскала**
- **Поиск пути и метрики:** 
  - **BFS**
  - **A***
- **Визуализация:** запись пошаговой истории в массив `AlgorithmStep` для покадровой анимации.

- Текущая версия приложения поддерживает только консольный вывод. Интерфейс в разработке.
---

## Инструкция по сборке

### Системные требования
* **JDK 25**
* **Apache Maven 3.8+**

### Пошаговая сборка
1. Откройте терминал и перейдите в корневую директорию проекта.
2. Выполните очистку и сборку исполняемого JAR-артефакта:
   ```bash
   mvn clean package
   ```


---

## Пример запуска

Запустите собранный JAR-файл из терминала:

```bash
java -jar target/Maze-generator-and-pathfinding-1.0-SNAPSHOT.jar
```
